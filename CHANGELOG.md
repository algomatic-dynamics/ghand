# Changelog

All notable changes to ghand are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- First public release: Dynamixel hand control with the `Hand` facade and
  operator runtime, the NiceGUI operator UI, MediaPipe webcam teleoperation and
  retargeting calibration, Rerun diagnostics, LeRobot dataset recording and
  policy rollout, MuJoCo asset export, and the `ghand doctor`
  hardware check.
- `lerobot_robot_ghand` plugin package so LeRobot discovers `--robot.type=ghand`.

Development history before this release is not public.
